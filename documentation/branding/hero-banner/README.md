# Home hero banner candidates (issue #140)

Four candidates generated for the Home page hero per spec §60.2 (geöffnetes Buch, dezente
Weltkarte, Lichtstrahlen, alte Bibliotheksatmosphäre), shown side-by-side against the existing
Bible-page hero (`bible-hero.jpg`) as a mood reference. **Chosen: C** — the world map reads as a
quiet background detail behind the light rays rather than competing with the book, unlike B/D
where the map is the dominant element (B also has illegible AI-generated pseudo-text on the map).

`candidate-C-konvergierendes-licht-original-ai.png` is the raw generated thumbnail (711×400 —
Canva's export API returned a permissions error on the freshly-created design both times it was
tried, the same issue hit when sourcing the favicon artwork, so no higher-resolution export was
available this time either). `candidate-C-shipped-1600w.jpg` (same file as
`wwwroot/images/home-hero.jpg`) is a bicubic upscale to 1600px wide, matching `bible-hero.jpg`'s
resolution — acceptable for a full-bleed background image shown with a gradient scrim over it,
unlike the favicon/logo mark which needed pixel-precise vector tracing.

A/B/D are kept here as reference/backup only, per the same convention as the logo candidates.
